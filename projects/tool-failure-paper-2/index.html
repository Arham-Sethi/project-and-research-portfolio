Paired queries and four conditions

Paper 2 studies a different intervention: a related tool is available even though the closed-domain question can be answered from model knowledge. Each domain pairs a tool-required query with a nearby closed-domain query and a checkable answer key. The three FULL notebooks each contain fifty such pairs.

Answering and invocation measures

The source records answer correctness separately from whether the tool was invoked. This lets the analysis detect a model that avoids an unnecessary call yet still withholds a correct answer. A call count alone would miss that behavior.
