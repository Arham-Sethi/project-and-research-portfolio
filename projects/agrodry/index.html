AgroDry (Stubby)

Image-based soil-moisture estimation

An image-upload interface and inference API for soil-moisture estimation, supported by preprocessing and frequency-aware training experiments.

Architecture

Connect a soil photograph to a readable moisture estimate and basic image-quality feedback.

02

Technical structure

ComponentImplementationRole
InterfaceHTML image-upload pagesImage selection and returned estimate
APIFastAPI routesHealth, version, prediction
Quality checksBrightness + sharpnessHeuristic image feedback
Model wrapperStub / TorchScript / ONNXConfigurable inference path
TrainingResNet + AFSC/DCT experimentsModel development material

The wrapper resizes images to 224 × 224 and uses normalized RGB tensors. It can fall back to the stub if a requested trained backend is unavailable; actual execution mode must be made explicit.

What this work establishes

The default inference mode is an illustrative stub. A public trained-model demonstration requires the correct export, backend configuration, and evaluation record. A displayed percentage is not evidence of physical water-content calibration.
